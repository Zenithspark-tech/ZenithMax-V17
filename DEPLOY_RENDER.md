# ZenithMax V17.1 — Free Render Deployment

This version is configured for Render's **Free** web-service plan.

## Important Free-plan limitation

The Free plan does **not** provide a persistent disk. ZenithMax therefore uses its normal local `./data` directory in this deployment. Uploaded files, local JSON data, and in-progress upload sessions can be lost after a service restart, redeploy, or other ephemeral-filesystem reset.

The application still supports **chunked/resumeable uploads during the same running instance** and uses URL-based external video discovery so no demo MP4 files are bundled into the repository.

For durable production media, move uploaded videos/photos/audio and the database to external persistent services (for example object storage + managed database) before treating this Free deployment as production storage.

## Deploy

1. In Render choose **New → Blueprint**.
2. Connect the GitHub repository containing this root `render.yaml`.
3. Select branch `main` and path `render.yaml`.
4. Confirm the service plan is **Free**.
5. Deploy the Blueprint.
6. After deployment, open the service → **Environment** and add:
   - `PEXELS_API_KEY` = your Pexels API key (optional)
   - `AI_API_URL`, `AI_API_KEY`, `AI_MODEL` (optional)
7. Verify `https://YOUR-RENDER-URL.onrender.com/api/health`.

## Notes

- JWT and refresh secrets are generated by Render.
- No Render persistent disk is requested in this Free configuration.
- Do not store secret API keys in GitHub.
